# 1.4 Introduction to Markov Decision Processes

Markov Decision Processes (MDPs) are the mathematical backbone of reinforcement learning. They extend Markov chains and bandits by adding **actions** and **rewards**, letting us model **sequential decision-making** under uncertainty.

---

## Why MDPs? Beyond Bandits

The **k-armed bandit** problem assumes a single situation: the agent picks one of $k$ actions and gets a reward. Real life doesn't work that way — different situations call for different actions.

> **Rabbit-in-the-field example (from the slides):**
> - **Situation A**: carrot on the right (reward +10), broccoli on the left (reward +3). The rabbit should go right.
> - **Situation B**: carrot on the left, broccoli on the right. The rabbit should now go left.
> - **Situation C (long-term trade-off)**: carrot on the right (+10), but a **tiger** waits behind it. Eating the carrot might mean getting eaten.
> - A *bandit rabbit* only cares about immediate reward and would go for the carrot.
> - A *smarter rabbit* weighs **long-term consequences** and chooses broccoli to survive.

This is exactly what MDPs formalize: the **best action depends on the state**, and actions influence **future states and future rewards**.

> **Analogy — Chess:** every board position is a *state*, every legal move is an *action*, and the value of a move depends on how it changes the position you face next turn. Sacrificing a queen today (low immediate reward) can lead to checkmate tomorrow (high future reward).

---

## What is an MDP?

An MDP is a mathematical framework for modeling decision-making where an **agent** interacts with an **environment** over a sequence of discrete time steps $t = 0, 1, 2, \dots$

### The MDP Tuple

Formally, an MDP is defined as:

```
M = (S, A, P, R, γ)
```

| Symbol | Meaning |
|--------|---------|
| **S** | Set of **states** the agent can be in |
| **A** | Set of **actions** the agent can take |
| **P** | **Transition probability** function |
| **R** | **Reward** function (immediate feedback) |
| **γ** | **Discount factor** (importance of future rewards), $0 \le \gamma \le 1$ |

### Core Terms

- **Agent** — the learner / decision-maker (e.g., the rabbit, a robot, a chess engine).
- **Environment** — everything the agent interacts with (the field, the grid world, the chess board).
- **State** $S_t$ — the current situation of the agent at time $t$.
- **Action** $A_t$ — the choice the agent makes at time $t$.
- **Policy** $\pi$ — the agent's strategy: a mapping from states to actions (the *thought process* behind picking an action).

> **Example — Robotic navigation (from the slides):**
> - **Agent:** autonomous robot.
> - **Environment:** grid layout, obstacles, target destination.
> - **State:** the cell the robot currently occupies.
> - **Action:** move up, down, left, right, or stay.
> - **Policy:** "move toward the goal while avoiding obstacles."

---

## The Markov Property

A state is **Markov** if it contains all the information needed to predict the future — **the present is sufficient, and remembering earlier states adds no value**.

This is why MDPs are tractable: you don't need to store the entire history, just the current state.

> **Analogy — Weather forecast (Markov chain):** if today's weather is *sunny*, tomorrow's forecast depends mostly on today, not on the weather last Tuesday. If "sunny" is a Markov state, knowing only "sunny" is enough.

---

## Dynamics: The Transition Function P

When the agent takes an action in a state, many **next states and rewards** are possible. The transition function captures all of this as a probability distribution.

Given a state $S_t$ and an action $A_t$, $P$ tells us the joint probability of the next state $S_{t+1}$ and the reward $R_{t+1}$:

```
P(s', r | s, a) = Pr{S_{t+1} = s',  R_{t+1} = r  |  S_t = s,  A_t = a}
```

### Properties of P

- **Non-negative:** $P(s', r \mid s, a) \ge 0$ for all $s', r, s, a$.
- **Sums to one:** $\sum_{s' \in S} \sum_{r \in R} P(s', r \mid s, a) = 1$.

That second property is what makes it a proper probability distribution — it accounts for every possible future outcome.

> **Example — Pac-Man:** from state "next to a power pellet" with action "eat," $P$ might say 90% you eat the pellet (+50 reward), 8% a ghost spawns nearby (-10), 2% the pellet was a decoy (0). Same state, same action — different stochastic futures.

---

## Returns and the Discount Factor

The agent doesn't just chase immediate reward; it maximizes the **return** $G_t$, the cumulative discounted reward from time $t$ onward:

```
G_t = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + ...
    = Σ_{k=0}^{∞} γ^k · R_{t+k+1}
```

- $\gamma = 0$ → agent is **myopic** (only immediate reward matters, like the bandit rabbit).
- $\gamma \to 1$ → agent is **far-sighted** (future rewards matter almost as much as present ones, like the tiger-aware rabbit).
- $\gamma$ is what lets MDPs encode *long-term thinking* mathematically.

---

## The Agent–Environment Loop

At every time step $t$:

1. The agent observes **state** $S_t$.
2. The agent picks **action** $A_t$ (according to its policy $\pi$).
3. The environment transitions to a new state $S_{t+1}$ with probability $P(\cdot \mid S_t, A_t)$.
4. The environment emits **reward** $R_{t+1}$.
5. Repeat.

This loop is the heartbeat of every RL algorithm. Everything from Q-learning to policy gradients is built on top of it.

---

## Key Takeaways

- **MDPs** formalize sequential decision-making with states, actions, rewards, and a discount factor: $M = (S, A, P, R, \gamma)$.
- They **generalize k-armed bandits** by making the best action depend on the *current state*, and by accounting for **long-term consequences** of actions.
- The **Markov property** says the current state is a sufficient statistic of the past — no history needed.
- The **transition function** $P(s', r \mid s, a)$ is a probability distribution over next states and rewards; it's non-negative and sums to 1.
- The **return** $G_t = \sum \gamma^k R_{t+k+1}$ captures cumulative discounted reward; $\gamma$ trades off immediate vs. future gains.
- Core terms: **agent**, **environment**, **state**, **action**, **policy** — the same five ideas show up in chess, robotics, Pac-Man, and the rabbit example.
- Without MDPs (or equivalents), there is no principled way to define *what the agent is trying to optimize* in reinforcement learning.
