# 1.6 Continuing Tasks

## Episodic vs. Continuing Tasks

Reinforcement learning problems are split into two flavours based on whether the agent–environment interaction has a natural ending.

- **Episodic tasks** — the interaction breaks into distinct episodes. Each episode has a clear start, a terminal state, and ends after a finite number of steps. Examples: a game of chess, a single round of Pong, solving a maze once.
- **Continuing tasks** — the interaction goes on forever. There is no terminal state; the agent just keeps acting, step after step. Examples: a smart thermostat regulating a building, running a power plant, monitoring a server, customer support.

**Why the distinction matters:** In episodic tasks we can sum rewards over the episode without worrying about whether the sum diverges. In continuing tasks the sum is over an *infinite* sequence of rewards — we need a mathematical trick to keep it finite.

**Quick analogy:** Chess is episodic (the board resets after checkmate). A power plant is continuing — the turbine never gets to "stop" and declare victory.

## Characteristics of Continuing Tasks

- **Ongoing nature:** persist over time, require continuous attention.
- **Regular intervals / no defined endpoint:** repeat indefinitely or until no longer needed.
- **Maintenance and monitoring:** the agent must keep observing and adjusting.
- **Evolution over time:** the optimal policy may change as conditions shift.

## Example: Smart Thermostat

A canonical continuing-task MDP:

- **Agent:** the thermostat controller.
- **Environment:** the building + its occupants.
- **State:** current temperature, time of day, number of people inside.
- **Actions:** `{turn heater on, turn heater off}` (two discrete actions).
- **Reward:** `−1` whenever a human has to manually adjust the temperature, `0` otherwise.

The thermostat must keep acting forever; there is no "done" state. It learns to anticipate user preferences so the humans never touch the dial.

## The Problem with Infinite Returns

For a continuing task starting at time `t`, the natural return is:

```
G_t = r_{t+1} + r_{t+2} + r_{t+3} + ...
```

Since we sum an *infinite* sequence of rewards, `G_t` might be infinite (e.g. if every reward is `+1`, the sum diverges). The agent then can't compare two infinite returns to choose between them. We need a fix.

## Discounting

The standard fix is to **discount future rewards** by a factor `γ` (gamma), called the discount rate, where `0 ≤ γ < 1`:

```
G_t = r_{t+1} + γ r_{t+2} + γ² r_{t+3} + γ³ r_{t+4} + ...
G_t = Σ_{k=0}^{∞} γ^k · r_{t+k+1}
```

- Immediate rewards are weighted by `γ^0 = 1` (full weight).
- A reward `k` steps in the future is multiplied by `γ^k`, shrinking it toward zero.

### Why the sum is now finite

Even if every reward is bounded by some constant `R`, the geometric series gives:

```
G_t ≤ R · Σ_{k=0}^{∞} γ^k = R / (1 − γ)
```

So the discounted return is guaranteed to be finite — the sum converges as long as `γ < 1`.

### Effect of γ on agent behaviour

- **γ = 0:** the agent is **myopic / shortsighted**. It only cares about the next reward `r_{t+1}`. "Live for the moment."
- **γ close to 1 (e.g. 0.99):** the agent is **farsighted**. Future rewards are almost as valuable as immediate ones. "Patient and strategic."
- **γ = 1:** no discounting — returns can blow up in continuing tasks, so this value is avoided in continuing settings (but is fine for episodic ones).

**Intuition / joke:** γ is basically how much the agent trusts the future. γ = 0 is a goldfish; γ = 0.99 is a careful investor; γ = 1 is a fantasy that only works in finite episodes.

## Key Takeaways

- **Episodic tasks** end at a terminal state; **continuing tasks** go on forever with no natural endpoint.
- Continuing tasks require the agent to balance ongoing maintenance and adapt over time.
- Summing undiscounted rewards over an infinite horizon can diverge — we need **discounting** to keep the return finite.
- The **discounted return** is `G_t = Σ_{k=0}^{∞} γ^k r_{t+k+1}` with `0 ≤ γ < 1`.
- **γ close to 0** ⇒ shortsighted agent (greedy, immediate reward); **γ close to 1** ⇒ farsighted agent (values future rewards).
- The geometric-series bound `R / (1 − γ)` guarantees the discounted return is finite.
- Choosing γ is a design lever that encodes how much the agent should value the future relative to the now.
