# 6. Review Course — Final Cheat Sheet for REL301m

> **One-sentence summary of the whole course:** *Reinforcement learning is the science of an agent learning a policy that maximises expected cumulative reward by interacting with an environment, and we have a toolbox — from bandits to policy gradients — for solving that problem with progressively weaker assumptions about the model.*

This review walks the **full arc** of the course: from single-state **k-armed bandits**, through **MDPs** and **dynamic programming**, then **model-free** prediction (Monte Carlo and TD), **model-free control** (SARSA, Q-learning, Expected SARSA), **planning and Dyna**, **function approximation**, **average reward**, and finally **policy-gradient / actor-critic** methods.

---

## Mental Map — How Every Chapter Connects

```
Bandits (no state, no dynamics)
   │   add states + transitions
   ▼
MDPs   (S, A, P, R, γ)  ── the formal problem
   │   assume we KNOW P and R
   ▼
Dynamic Programming  ── Policy Evaluation, Policy Iteration, Value Iteration
   │   drop the model assumption
   ▼
Model-free learning
    ├── Monte-Carlo      (learn from complete episodes)
    ├── Temporal-Difference (learn from one-step samples)
    │       ├── on-policy: SARSA, Expected SARSA
    │       └── off-policy: Q-learning
    │   add a learned model
    ▼
Planning & Dyna  ── Dyna, Dyna-Q+, dealing with model error
    │   swap tables for function approximators
    ▼

    │   keep going on infinite-horizon tasks
    ▼
Average-Reward formulation  ── differential return, differential value
    │   directly optimise the policy
    ▼

```

> **Joke to remember the order:** *"Bandits walk into an MDP, ask the Dynamic Programmer, who says 'Monte Carlo it, then TD it, Q-learn it, plan it, approximate it, average it, and finally just gradient-it.'"*

## 1. The k-Armed Bandit Problem

- **Setting:** k actions, one step, no state. Pick an arm, get a stochastic reward, repeat.
- **Action value:** `q*(a) = E[ R_t | A_t = a ]` — the *true* expected reward of arm `a`.
- **Sample-average estimate:** `Q_t(a) = (1/N_t(a)) Σ_i r_i`.
- **Greedy action:** `A_t = argmax_a Q_t(a)`.
- **Exploration vs Exploitation** — the central tension.
  - **ε-greedy:** with probability ε pick a random arm; otherwise play the greedy one.
  - **Optimistic initial values / UCB** — push initial Q high to encourage early exploration.
- **Real-life analogies:** clinical trials (which drug works best?), A/B testing, choosing a coffee shop.

> **Key insight:** Bandits have **no dynamics** — the chosen action does *not* change the next observation. That's the only thing that separates them from MDPs.

---

## 2. Markov Decision Processes (MDPs)

The formal problem definition — everything else in RL builds on this.

```
M = (S, A, P, R, γ)
```

| Symbol | Meaning |
|---|---|
| **S** | Set of states |
| **A** | Set of actions |
| **P** | Transition kernel `P(s', r | s, a)` |
| **R** | Reward function |
| **γ** | Discount factor, `0 ≤ γ ≤ 1` |

### Key ingredients

- **Markov property:** the current state is a sufficient statistic of the past.
- **Return:** `G_t = R_{t+1} + γ R_{t+2} + γ² R_{t+3} + ... = Σ_{k≥0} γ^k R_{t+k+1}`.
- **γ = 0** → myopic (bandit-like). **γ → 1** → far-sighted.
- **Agent–environment loop:** `S_t → A_t → (S_{t+1}, R_{t+1})` repeated forever.

> **Analogy:** The rabbit-in-the-field story. Carrot today might mean tiger tomorrow — MDPs are built so the agent can *think ahead*.

### Episodic vs Continuing

- **Episodic:** the interaction breaks into episodes that end in a terminal state.
- **Continuing:** the task goes on forever (average-reward regime comes in later).

---

## 3. Policies and Value Functions

- **Policy π:** mapping from states to action probabilities — `π(a | s)` (stochastic) or `π(s)` (deterministic).
- **State-value function:** `v_π(s) = E_π[ G_t | S_t = s ]`.
- **Action-value function:** `q_π(s, a) = E_π[ G_t | S_t = s, A_t = a ]`.
- **Bridge:** `v_π(s) = Σ_a π(a|s) q_π(s, a)`.

---

## 4. Bellman Equations — The Engine of RL

### Bellman Expectation Equation (given π)

```
v_π(s) = Σ_a π(a|s) Σ_{s', r} p(s', r | s, a) [ r + γ v_π(s') ]
q_π(s, a) = Σ_{s', r} p(s', r | s, a) [ r + γ Σ_{a'} π(a'|s') q_π(s', a') ]
```

### Bellman Optimality Equation (best possible)

```
v*(s) = max_a Σ_{s', r} p(s', r | s, a) [ r + γ v*(s') ]
q*(s, a) = Σ_{s', r} p(s', r | s, a) [ r + γ max_{a'} q*(s', a') ]
```

### Bridges to optimality

```
v*(s) = max_a q*(s, a)
π*(s) = argmax_a Σ_{s', r} p(s', r | s, a) [ r + γ v*(s') ]
```

> **Mnemonic for the expectation backup:** *Policy picks the action, Environment picks the outcome, Reward is grabbed, Discount is applied — **PERD**.*

The Bellman equations turn an **infinite sum over trajectories** into a **system of |S| linear equations**. In tiny MDPs we solve them directly; in realistic ones we use iterative / sample-based methods.

## 5. Dynamic Programming (model-based planning)

Assumes we **know P and R**.

### Policy Evaluation (Prediction)

Iteratively apply the Bellman expectation backup until `v_π` converges.

### Policy Iteration (Control)

```
π_0 → E  (evaluate v_{π_0})
      → I  (greedy improvement: π_{k+1}(s) = argmax_a Σ p(s',r|s,a)[r + γ v_{π_k}(s')])
      → E  → I  → ...  until π stops changing.
```

Policy iteration converges in a finite number of steps in the worst case (and very few in practice).

### Value Iteration

Combines evaluation + improvement in one sweep:

```
v_{k+1}(s) = max_a Σ_{s', r} p(s', r | s, a) [ r + γ v_k(s') ]
```

Converges to `v*`. Then recover `π*(s) = argmax_a Σ p(s',r|s,a)[r + γ v*(s')]`.

### Generalized Policy Iteration (GPI)

The general idea: keep two processes — evaluation making `v` consistent with `π`, improvement making `π` greedy w.r.t. `v` — running in parallel. Almost *every* RL algorithm is a flavour of GPI.

---

## 6. Monte-Carlo (MC) Methods

### Core idea

**Learn value functions by averaging the actual returns observed after visiting a state** — no model needed, but the episodes must terminate.

```
V(s) = average of returns observed following visits to s
```

- **First-visit MC:** average returns from the first visit per episode.
- **Every-visit MC:** average returns from every visit per episode.

### MC for Control

- **On-policy first-visit MC control:** alternate *evaluation* (sample returns for current π) with *ε-soft improvement*.
- **Exploring-starts:** initial state–action pair randomised to give every (s, a) a chance.
- **ε-soft policies:** every action has probability ≥ ε/|A| so exploration never dies.

### Off-policy MC (Importance Sampling)

- **Behavior policy `b`** generates the data.
- **Target policy `π`** is what we want to learn about.
- **Importance-sampling ratio:** `ρ_{t:T-1} = Π_{k=t}^{T-1} π(A_k|S_k) / b(A_k|S_k)`.
- **Ordinary importance sampling** (unbiased, high variance) vs **weighted importance sampling** (biased, low variance).

---

## 7. Temporal-Difference (TD) Learning

The **conceptual bridge** between MC and DP.

### TD target & error

```
TD target  = R_{t+1} + γ V(S_{t+1})
δ_t        = R_{t+1} + γ V(S_{t+1}) − V(S_t)
```

### TD(0) update

```
V(S_t) ← V(S_t) + α · δ_t
```

### Comparison table

| Property | DP | MC | TD(0) |
|---|---|---|---|
| Needs model? | Yes | No | No |
| Bootstraps? | Yes | No | Yes |
| Updates when? | sweep | end of episode | every step |
| Works in continuing tasks? | Yes | No | Yes |

> **Real-life analogy — daily commute.** You don't wait until the office to fix your ETA estimate. Halfway there, you glance at the clock and revise the prediction. That's TD.

### n-step TD & TD(λ)

- **n-step return:** `G_t^(n) = R_{t+1} + γ R_{t+2} + ... + γ^{n-1} R_{t+n} + γ^n V(S_{t+n})`.
- **λ-return:** geometric average of n-step returns over `n = 1, 2, ...`.
- **Eligibility traces** implement TD(λ) online with a single update per step:
  `E_t(s) = γ λ E_{t-1}(s) + 1(S_t = s)` (accumulating) or `E_t(s) = γ λ E_{t-1}(s)` (replacing).

## 8. TD Control — SARSA, Q-Learning, Expected SARSA

All three act on `Q(s, a)`.

### SARSA (on-policy)

```
Q(S, A) ← Q(S, A) + α [ R + γ Q(S', A') − Q(S, A) ]
```

The quintuple `(S, A, R, S', A')` gives the name. Learns the value of the **behaviour policy**, including its exploration noise.

### Q-Learning (off-policy)

```
Q(S, A) ← Q(S, A) + α [ R + γ · max_a Q(S', a) − Q(S, A) ]
```

The `max` makes it directly solve the Bellman **optimality** equation, no matter how exploratory `b` is.

> **Joke — The optimist vs the realist.** *Q-learning is the eternal optimist: "next time I'll take the best move." SARSA is the cautious realist: "next time I'll probably do what I just did."*

### Expected SARSA

```
Q(S, A) ← Q(S, A) + α [ R + γ Σ_a π(a|S') Q(S', a) − Q(S, A) ]
```

Same update target as Q-learning but without the `max`'s high-variance cliff — unbiased and lower variance.

---

## 9. Planning, Models, and Dyna

- **Model:** anything the agent can use to predict environment responses (`P̂`, `R̂`).
- **Planning:** any computation that uses the model to improve the policy *without* further environment interaction.
- **Dyna-architecture:** at each real step, (1) update Q from real experience, then (2) run *k* simulated steps using the learned model to drive the *same* Q-learning update. Real + simulated experience improves the policy together.
- **Dyna-Q+:** add a small bonus for *less-visited* state-action pairs to keep exploring when the model is incomplete.
- **Inaccurate models:** keep the planning horizon short, stochastic models, or use distribution-model-based planning.

---

## 10. Function Approximation

Real-world state spaces are too big for tables. Approximate the value function with a parameter vector `w`:

```
v̂(s, w) ≈ v_π(s)
```

### Supervised-learning framing

- Training set = `(state, target)` pairs sampled from experience.
- Loss = expected squared error `E_π[ (v_π(S) − v̂(S, w))² ]`.

### Linear FA

`v̂(s, w) = x(s)ᵀ w`. SGD on the TD error gives the **Linear TD(0)** update:

```
w ← w + α [ R + γ v̂(S', w) − v̂(S, w) ] x(S)
```

Semi-gradient method (target is treated as fixed when differentiating).

### Feature construction

- **Coarse coding**, **tile coding**, **radial basis functions**, **neural-network embeddings**.
- **Why generalise?** Two similar states share features, so learning in one helps the other — that's the *whole point* of FA.

### Episodic Semi-gradient SARSA with FA

Replace tabular `Q` with `q̂(s, a, w)`. Update `w` after every step with the semi-gradient of the squared TD error.

---

## 11. Exploration under Function Approximation

Tabular exploration tricks (ε-greedy, optimistic init) do **not** simply transfer to FA — partial observability and generalisation mean an agent can lock onto a misleading local optimum.

- Use **noisy / exploratory policy parameterisations** (e.g. softmax with high temperature).
- Track **pseudo-counts** in feature space for intrinsic motivation.
- Rely on off-policy algorithms (Q-learning) which still converge (with care) under function approximation.

---

## 12. Average-Reward Formulation

For **continuing tasks** (no discount γ chosen to make sums finite), optimise the *long-run average reward per step*:

```
r(π) = lim_{h → ∞} E[ (1/h) Σ_{t=1}^{h} R_t | π ]
```

- **Differential return:** `G_t = Σ_{k=1}^{∞} ( R_{t+k} − r(π) )`.
- **Differential value:** `v(s) = E[ G_t | S_t = s ]`.
- **Differential Bellman equations** mirror the discounted ones with `r(π)` subtracted from every reward.
- **R-learning, differential semi-gradient SARSA**: practical average-reward control algorithms.

## 13. Policy-Gradient & Actor-Critic Methods

### Parameterised policies

```
π(a | s, θ)   with softmax over preferences h(s, a, θ):
π(a | s, θ) = exp(h(s,a,θ)) / Σ_b exp(h(s,b,θ))
```

### Policy-gradient theorem (episodic)

```
∇ J(θ) ∝ Σ_s μ(s) Σ_a q_π(s, a) ∇ π(a | s, θ)
```

`μ(s)` is the on-policy state distribution.

### REINFORCE (Monte-Carlo policy gradient)

```
Δθ = α · G_t · ∇ ln π(A_t | S_t, θ)
```

If return is high → make that action more likely. If low → make it less likely.

### Baselines

Subtract any function `b(s)` that does not depend on `a` to reduce variance without changing expectation:

```
Δθ = α · ( G_t − b(S_t) ) · ∇ ln π(A_t | S_t, θ)
```

A common choice is `b(s) = v̂(s, w)`.

### Actor–Critic

- **Actor:** the parameterised policy `π(a|s,θ)`.
- **Critic:** a learned value function `v̂(s, w)` (often with FA).
- **Advantage:** `Â_t = R_{t+1} + γ v̂(S_{t+1}, w) − v̂(S_t, w)` replaces the high-variance return `G_t`.

### Continuing-task policy gradient

Using the average-reward formulation:

```
∇ J(θ) ∝ Σ_s μ(s) Σ_a ( q_π(s,a) − r̄ ) ∇ π(a | s, θ)
```

### Policy parameterisations (continuous actions)

- **Gaussian policy:** `π(a | s, θ) = N(μ(s,θ), σ²)` — sample continuous actions directly.
- **Squashed Gaussian / tanh-Gaussian:** keep actions bounded for actuator limits.
- **Energy-based policies** for more expressive distributions.

> **Real-life analogy — the recipe.** A tabular policy is a phone book of every state. A parameterised policy is a recipe: a small set of numbers (`θ`) that scales across millions of states.

## 14. Algorithm Family Cheat-Sheet

| Need | Algorithm |
|---|---|
| Best action in a stationary bandit | ε-greedy / UCB / gradient bandits |
| Plan in a known small MDP | Policy / Value Iteration |
| Learn V from episodes, no model | First-visit / every-visit MC |
| Learn V online, no model | TD(0), TD(λ) with eligibility traces |
| Learn Q online, on-policy | SARSA |
| Learn Q online, off-policy | Q-learning |
| Lower-variance off-policy target | Expected SARSA |
| Combine real + simulated experience | Dyna, Dyna-Q+ |
| Generalise across states | Linear FA, DQN-style deep FA |
| Continuing tasks without γ | Differential (average-reward) methods, R-learning |
| Continuous / high-dim actions | Policy gradient, REINFORCE, Actor–Critic |
| Modern scalable policy | PPO / SAC / TD3 family (built on top of all of this) |

## Key Takeaways — Final Exam Cheat Sheet

- **RL in one sentence:** An agent learns a policy that maximises expected cumulative reward by interacting with an environment.
- **Bandits are MDPs with one state.** They isolate the exploration–exploitation trade-off.
- **MDPs** = `(S, A, P, R, γ)`. The Markov property lets us plan with only the current state.
- **Bellman equations** are the recursive heart of RL — expectation form for a fixed π, optimality form for π*.
- **DP** (Policy/Value Iteration) needs the model and gives exact solutions for small MDPs.
- **MC** learns from complete episodes using actual returns; **TD** learns one step at a time and bootstraps.
- **SARSA** is on-policy, **Q-learning** is off-policy, **Expected SARSA** removes the `max` variance.
- **Dyna** blends model-free and model-based RL: every real step is followed by *k* simulated steps through the learned model.
- **Function approximation** lets RL generalise across huge state spaces; linear methods are the cleanest to analyse.
- **Average-reward / differential** formulation is the right tool for continuing tasks where discounting is not natural.
- **Policy-gradient** methods (REINFORCE, Actor–Critic) directly optimise a parameterised policy and handle continuous actions.
- **Always remember the three recipes:** *Plan if you can, learn from samples if you must, parameterise if the world is big.* Together they are the entire REL301m toolkit.
