# 3.4 Linear Temporal Difference

## Overview

This lesson extends tabular TD learning to the **linear function approximation** setting, shows that tabular TD is a special case of the linear formulation, and characterizes the **TD fixed point** that linear TD converges to (on-policy, under linear FA).

> **Analogy:** Think of a state's value as a weighted average of its features — the feature vector `x(s)` is like a recipe's ingredient list, and the weight vector `w` is the amount of each ingredient to add.

## Linear Function Approximation Setup

The approximate value of a state is a **linear combination** of its features:

```
V̂(s, w) = x(s)ᵀ w
```

where:

- `x(s)` is the **feature vector** for state `s` (an `n × 1` column vector)
- `w` is the **weight vector** (an `n × 1` column vector of learnable parameters)
- `x(s)ᵀ w` is the inner product = a scalar value estimate

The gradient of the linear approximator is trivial — and that's the key reason linear TD is so clean:

```
∇_w V̂(s, w) = x(s)
```

> **Joke:** "In linear FA, the gradient is just the feature vector — no calculus, no fuss, just a hand on the ingredients list."

## Semi-Gradient TD Update

The semi-gradient TD update for linear function approximation:

```
w ← w + α · [R_{t+1} + γ · V̂(S_{t+1}, w) - V̂(S_{t+1}, w)] · x(S_t)

w ← w + α · δ_t · x(S_t)
```

where `δ_t` is the **TD error** at time `t`.

### Why "semi-gradient"?

The target `R_{t+1} + γ · V̂(S_{t+1}, w)` still depends on `w`, but we only differentiate `V̂(S_t, w)` — not the bootstrap target. Hence "semi"-gradient.

### Interpreting the update

- The weight update is in the **direction of the feature vector** `x(S_t)`, scaled by the TD error `δ_t`.
- If a feature is **large**, the corresponding weight can have a **large impact** on the prediction.
- If a feature is **zero**, that weight has **no impact** and its gradient is also zero — it never gets updated.
- The TD error `δ_t` measures the "surprise" between the predicted value and the better-informed bootstrap target.

## Tabular TD is a Special Case of Linear TD

With a **one-hot feature vector** for each state (one feature per state, exactly one feature equals 1 — the one for the current state — and all others are 0):

```
x(s)ᵀ w = w_i   where s = s_i
```

So the value estimate for `s_i` is just the `i`-th weight. The linear semi-gradient TD update becomes:

```
w_i ← w_i + α · δ_t
```

which is **exactly the tabular TD update** from earlier lessons. This means:

- Tabular TD = linear TD with one-hot features
- **State aggregation** (grouping states that share features) is also a special case of linear TD — many states share the same non-zero feature entries, so they share the same weight and therefore the same value estimate.

> **Real-life example:** Imagine rating restaurants. A one-hot feature vector would be a checklist of 1000 restaurants with exactly one checkmark — that's "tabular." Linear FA instead lets you say "this restaurant has features: cheap, romantic, noisy" with weights for each feature. Multiple restaurants share the same feature profile, so they share a rating — that's state aggregation.

## The Expected TD Update

Define the expected TD update as the expected change in `w` at each step (treating the current weight as fixed inside the expectation):

```
E[Δw_t] = α · (b - A · w_t)
```

Pulling `x_t` inside the brackets and using `(a scalar)ᵀ = (a scalar)`, we can write:

```
A = E[ x_t (x_t - γ · x_{t+1})ᵀ ]     (an n × n matrix)
b = E[ R_{t+1} · x_t ]                (an n × 1 vector)
```

Both `A` and `b` are expectations taken over the on-policy state distribution (the distribution of states visited under the behavior policy).

### Why this decomposition matters

The stochastic update `w ← w + α · δ_t · x_t` can be split into:

- an **expected (deterministic) update** `(b - A · w_t)` — drives convergence
- a **noise term** with mean zero — vanishes in expectation

So the long-run behavior is dominated by `(b - A · w_t)`.

## The TD Fixed Point

Weights have converged when the **expected TD update is zero**:

```
b - A · w_TD = 0
```

If `A` is invertible:

```
w_TD = A⁻¹ b
```

More generally, `w_TD` is **a solution to the linear system** `A · w = b`.

> **Key insight:** This is the generalization of the Bellman equation to the function-approximation setting. The TD fixed point is a *linear-system* fixed point rather than a tabular value-iteration fixed point.

### A "value error" view

Define the **value error** as the expected squared difference between the true value `v_π(s)` and the approximation `V̂(s, w)`. The TD fixed point `w_TD` is **not** the same as the weight vector that minimizes the value error.

A useful approximation: if we can write the true value as `v_π(s) = x(s)ᵀ w_*` for some true weight vector `w_*` (i.e. the function class is "rich enough"), then:

- **Minimum value error** is the projection of `v_π` onto the function class: `w_* = Π · w_*` (solved directly from the projection).
- **TD fixed point** is `w_TD = A⁻¹ b`.

The difference between these two solutions is small when `γ` is small (one-step bootstrapping dominates) and can be **large when `γ` is close to 1** (long bootstrapping chains amplify the projection error).

> **Real-life example:** Predicting your course grade at the end of the year by chaining together short-term predictions (assignment scores) works well when each prediction is reasonably accurate. But predicting the final grade by recursively predicting ever-further-future grades amplifies every small mistake — that's the `γ → 1` regime.

## What This Connects To

- The TD fixed point `A · w = b` is a clean **objective** view of TD learning — it links TD to a generalized Bellman-style linear system.
- Linear TD is the rare function-approximation setting where we can prove convergence and characterize the limit exactly. For **non-linear FA** (neural networks), the same kind of fixed-point analysis breaks down.
- Semi-gradient methods (including linear TD) **do not** converge to the minimum value error — they converge to `w_TD`, which is generally different from the projection of the true value function.

## Key Takeaways

- **Linear FA:** `V̂(s, w) = x(s)ᵀ w`, and the gradient is simply `x(s)` — no calculus needed.
- **Semi-gradient TD update:** `w ← w + α · δ_t · x(S_t)`; features with larger magnitudes move weights more, zero-valued features are inert.
- **Tabular TD is a special case** of linear TD using one-hot feature vectors; state aggregation is another special case.
- **Expected update:** `E[Δw_t] = α · (b - A · w)` with `A = E[x_t (x_t - γ x_{t+1})ᵀ]` and `b = E[R_{t+1} x_t]`.
- **TD fixed point:** `w_TD = A⁻¹ b` (when `A` is invertible) — the linear-system generalization of the Bellman equation.
- The TD fixed point differs from the **minimum-value-error** solution; the gap grows as `γ → 1`.
- Linear TD is the cleanest function-approximation setting: convergence is provable and the limit is exactly characterizable as a linear system.
