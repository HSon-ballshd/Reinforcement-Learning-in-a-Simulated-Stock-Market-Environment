# 3.3 The Objective for Temporal Difference

Study notes for a university Reinforcement Learning course. This deck explains **why TD learning is called a *semi-gradient* method**, what objective it actually minimizes, and how it compares to Gradient Monte Carlo.

## Learning Objectives

By the end of this lecture you should be able to:

- Write down the **TD update for function approximation** and explain each term.
- Explain why TD is a **semi-gradient** method (not a true stochastic gradient descent).
- Argue why semi-gradient TD can converge to a **biased** value estimate.
- Compare TD and Gradient Monte Carlo along several axes (timing, bootstrapping, bias, variance, sample efficiency).

## Recap: Gradient Monte Carlo (GMC)

Gradient Monte Carlo is the "vanilla" baseline. It fits the value function `V̂(s, w)` by stochastic gradient descent on the squared error against a sample of the actual return `G_t` (the discounted sum of rewards collected from `t` to the end of the episode).

The update looks like this conceptually:

```
w ← w + α · [ G_t − V̂(s, w) ] · ∇V̂(s, w)
```

Key property: `G_t` is a **sample of the true return**. It does not depend on `w`. Therefore GMC performs **unbiased stochastic gradient descent** on the Mean Squared Value Error (MSVE), and — under appropriate conditions — converges to a **local minimum** of MSVE.

A natural question: *what if we swap `G_t` for a different "target" `U_t`?* Any unbiased estimate of `v_π(s)` plugged in here would still give a true gradient step.

## The TD Update for Function Approximation

The one-step TD target is the natural alternative:

```
U_t  =  R_{t+1} + γ · V̂(s_{t+1}, w)
```

The corresponding update is:

```
w ← w + α · [ R_{t+1} + γ · V̂(s_{t+1}, w) − V̂(s, w) ] · ∇V̂(s, w)
```

Here `R_{t+1}` is the **immediate reward** and `γ · V̂(s_{t+1}, w)` is the **bootstrapped estimate** of what comes next. If `U_t` were an unbiased sample of `v_π(s)`, this would still be a clean SGD step on the squared error — exactly as in Monte Carlo.

> **Analogy:** Imagine you are a student estimating how hard tomorrow's exam will be. Gradient Monte Carlo waits until you have actually sat every previous exam (`G_t`). TD glances at tomorrow's syllabus and uses your *current guess* about it (`V̂(s', w)`) as a stand-in. Faster, but built on shaky scaffolding.

## Why TD is a *Semi*-Gradient Method

Here's the catch: `V̂(s_{t+1}, w)` inside the target is itself a function of the very weights `w` we are trying to update. If we take the gradient of the squared error

```
½ · [ U_t − V̂(s, w) ]²   with   U_t = R_{t+1} + γ · V̂(s_{t+1}, w)
```

the chain rule gives:

```
∇_w ½ [ U_t − V̂(s, w) ]²  =  − [ U_t − V̂(s, w) ] · ∇_w V̂(s, w)
                          −  [ U_t − V̂(s, w) ] · γ · ∇_w V̂(s_{t+1}, w)
```

A *true* gradient descent step would include **both** terms — the gradient of the prediction *and* the gradient of the target through `w`.

TD, however, **ignores the second term**. It pretends the target is fixed at the moment of the update and only differentiates through `V̂(s, w)`. That truncated derivative is why we call the method a **semi-gradient**.

> **Joke:** Semi-gradient is like a tourist who only looks at the map but ignores the fact that the map itself is being redrawn under their feet.

## The TD Objective (Projected Bellman Error)

If TD isn't doing true gradient descent, *what is it minimizing?*

It minimizes a closely related quantity called the **Projected Bellman Error (PBE)**. Intuitively:

- The **Bellman error** at a state is `R + γ · V̂(s') − V̂(s)`.
- We want `V̂` to be the closest possible function to the true value function `v_π` within the space representable by our approximator (e.g., the span of linear features).
- The Bellman error is first projected onto this representable subspace, then squared and averaged.

The fixed point of semi-gradient TD(0) is the minimum of the **Projected Bellman Error**, **not** the minimum of the MSVE. Hence TD's estimate of `v_π` is generally **biased**.

## Convergence Properties Compared

| Property | Gradient Monte Carlo | Semi-Gradient TD |
|---|---|---|
| Update timing | End of episode (or `G_t` available) | Every step |
| Bootstrapping | No — uses real return | Yes — uses `V̂(s', w)` |
| Gradient | True SGD on MSVE | Semi-gradient on PBE |
| Convergence | Local minimum of **MSVE** | Minimum of **Projected Bellman Error** (biased for MSVE) |
| Variance | High (return is noisy) | Lower |
| Bias | Unbiased | Biased in general |
| Sample efficiency | Lower | Higher |

**Bottom line:** TD trades bias for lower variance and faster online learning. In practice that trade-off is almost always worth it; on-policy semi-gradient TD(0) with linear function approximation still converges (to a TD fixed point), and off-policy variants with a few extra tricks can converge to the TD fixed point as well.

## Real-Life Analogies

1. **Sales forecasts.** You estimate next quarter's sales. MC waits for the quarter to actually finish and books the result. TD nudges the estimate every week using last week's actual numbers *plus* your current guess about the weeks ahead. Quicker, slightly self-fulfilling.
2. **Student GPA.** MC updates your GPA only at the end of the semester using the final grade. TD updates after every assignment, using the assignment score plus an estimate of how you'll do on the remaining work — that estimate is itself influenced by how you've been doing.
3. **Navigation apps.** ETAs aren't computed from a stored record of past trips; they extrapolate from current speed and recent conditions (a TD-style bootstrap). They're reactive but can be systematically optimistic on a brand-new road.

## Key Takeaways

- **Gradient Monte Carlo** does unbiased SGD on the **Mean Squared Value Error** using the sampled return `G_t`.
- The **TD update** replaces `G_t` with the one-step bootstrap target `R_{t+1} + γ · V̂(s_{t+1}, w)`.
- Because the target depends on `w`, TD drops the gradient through `V̂(s_{t+1}, w)` — it is a **semi-gradient method**, not true SGD.
- Semi-gradient TD minimizes the **Projected Bellman Error**, not the MSVE, so its fixed point is generally a **biased** estimate of `v_π`.
- Compared to MC: TD has **lower variance, higher bias, better sample efficiency**, updates **every step** (online), and **bootstraps** from current value estimates.
- On-policy linear semi-gradient TD(0) still converges to a well-defined fixed point, which is why it remains the workhorse of value-based RL with function approximation.
