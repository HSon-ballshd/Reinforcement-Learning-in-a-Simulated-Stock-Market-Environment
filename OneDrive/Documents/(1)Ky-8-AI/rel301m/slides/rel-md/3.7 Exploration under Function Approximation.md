# 3.7 Exploration under Function Approximation

When you move from a tabular MDP to a function approximator (linear features, tile coding, neural networks), the agent no longer has a separate, isolated entry for every state. A single weight update can nudge the value of many states at once. That coupling is great for generalization and terrible for the simple exploration tricks you used to rely on. This note covers the two main workhorses — **optimistic initial values** and **ε-greedy** — and explains why each behaves differently when values are learned through a function.

---

## Why exploration gets harder with function approximation

In the tabular case every state-action pair has its own slot. If you visit a state once and lower its estimate, every other state is unaffected. That property is what makes **directed exploration** (e.g. optimism) provably systematic — you can guarantee that "untried" states still look attractive and will eventually be tried.

Under function approximation (FA), an update at one state is broadcast across every other state that shares features or weights:

```
V̂(s; w) ≈ x(s)ᵀ w          (linear FA)
Q̂(s,a; w) ≈ x(s,a)ᵀ w       (linear FA for action values)
```

If a feature is shared by many states, lowering `wᵢ` after a single bad experience drags down the value of states you have **never even visited**. So the very mechanism that lets FA generalize also wrecks the systematic exploration we used to get for free.

> Analogy: in a huge maze you cannot try every cell. FA says "this corner was bad, so the opposite corner probably is too." That is great for learning — but it means you may stop exploring the opposite corner long before you have actually been there.

## Optimistic Initial Values

### Tabular recap
The idea is dead simple: **initialize every action-value estimate above the largest possible return**.

```
Q̂(s,a) ← R_max   for all s, a
```

Because updates only touch the visited pair, an unvisited state keeps its optimistic value forever and looks more attractive than anything the agent has actually tried. The agent is forced to try each state-action pair at least once before its estimate can fall below the true value.

### Under function approximation
You translate the same idea into weights:

```
Initialize w so that Q̂(s,a; w) ≥ R_max   for every (s,a)
```

- **Binary features / tile coding:** straightforward. If every state has at least one active feature, set each weight to `R_max` (or larger). Then any linear combination of active features is also optimistic.
- **Linear FA, more general features:** still workable as long as you can reason about the range of `x(s)ᵀ w`.
- **Non-linear FA (e.g. neural networks):** the mapping from weights to values is highly non-convex. You may not be able to construct a weight setting that is uniformly optimistic — and you almost certainly will not stay optimistic after a few updates.

### The killer problem: generalization erodes optimism
Consider the extreme case of a **single feature that is always 1** (a constant bias). Optimistic initialization just sets that bias high. After the first observed transition, the bias shrinks a bit — and **every single state's value drops along with it**, including states you have never visited. The systematic exploration guarantee evaporates.

Tile coding limits this by making updates **local** — only a small subset of weights (the active tiles) is touched per update, leaving untouched states still optimistic. Neural networks sit between the two extremes: with care they can be locally updated, but they also tend to **generalize aggressively**, so optimism tends to leak.

## ε-Greedy

### What it is
Pick the greedy action with probability `1 - ε`, otherwise pick uniformly at random:

```
a_t ← argmax_a Q̂(s_t, a; w)        w.p. 1 - ε
a_t ∼ Uniform(A)                    w.p. ε
```

This is the universal fallback for FA because it only requires **action-value estimates** — it does not care how they were computed.

### Why it still works under FA
- No assumption of state-isolation.
- No need to reason about the geometry of the value surface.
- Plays nicely with non-linear approximators and off-policy data.

### Why it is unsatisfying
ε-greedy is **random / undirected exploration**. It does not bias toward uncertainty or novelty; it just sprinkles noise and hopes something informative shows up.

- It is **not as systematic** as optimism-based methods.
- In large action spaces it wastes samples on clearly bad actions.
- It does not give you a GLIE-style guarantee ("every action is taken infinitely often in the limit") unless you anneal `ε` to zero — and even then, FA may have erased the evidence of an action before you ever try it.

> Joke: ε-greedy is the RL equivalent of bumping into every wall of a dark room. You will eventually find the door, but you will also memorize where the coat rack is.

---

## How the two methods compare

| Aspect | Optimistic Initialization | ε-Greedy |
| --- | --- | --- |
| Needs estimates only | Yes | Yes |
| Directed / systematic | Yes (tabular), partial (FA) | No — random |
| Works with non-linear FA | Hard | Easy |
| Robust to aggressive generalization | No | Yes |
| Tuning knob | Magnitude of optimistic init | `ε` schedule |

In practice: **ε-greedy is the default under FA**, and optimism is layered on carefully (e.g. via exploration bonuses, UCB-style terms, or noisy nets) when you want directed exploration that survives generalization.

---

## Practical recipes

- **Linear FA with binary / tile features:** safe to use optimistic initialization — set weights near `R_max`.
- **Neural networks:** prefer ε-greedy (or Boltzmann / entropy-regularized softmax), plus exploration bonuses such as count-based or random-network-distillation (RND) bonuses.
- **Decaying ε** (e.g. `ε_t = 1/t`) gives a GLIE-like schedule: every action keeps being tried, but exploration fades as the policy converges.
- Watch out for **deadly triads**: off-policy data + bootstrapping + FA make value estimates brittle, and bad exploration amplifies the brittleness.

---

## Key Takeaways

- Function approximation couples states through shared weights, so a single update can destroy the optimism of states you have never visited.
- **Optimistic initialization** is straightforward for tabular and for FA with localized features (tile coding), but breaks down with aggressively generalizing or non-linear approximators.
- **ε-greedy** is the universal, easy-to-use fallback for FA — it is undirected and not systematic, but it makes no assumptions about the value surface.
- Linear FA + binary features ≈ behaves like tabular; **neural FA** demands more sophisticated exploration than naive optimism or constant ε.
- Annealing ε is the cheapest way to get a GLIE-flavored guarantee ("try everything eventually, exploit more as you learn") under FA.
- For exam-style questions: the punchline is *"tabular exploration guarantees do not transfer to FA — generalization eats optimism."*
