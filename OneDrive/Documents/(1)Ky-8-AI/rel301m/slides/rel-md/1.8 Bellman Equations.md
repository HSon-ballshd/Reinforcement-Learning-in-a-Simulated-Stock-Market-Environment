# 1.8 Bellman Equations — Study Notes

## What is the Bellman Equation?

The **Bellman equation** is the cornerstone of dynamic programming and reinforcement learning. It expresses a recursive relationship: the value of a state (or a state-action pair) is equal to the expected immediate reward plus the **discounted** value of its successor states.

In plain English: *"The value of where I am now = what I get right now + a discounted version of what I'll get from where I'll be next."*

This recursion is what lets RL algorithms (value iteration, policy iteration, Q-learning, SARSA, ...) compute value functions without enumerating every possible trajectory.

> **Analogy:** Imagine planning a road trip from city A. The *value* of A is the cost of driving to the next city plus the discounted cost of the rest of the trip. If future miles feel less urgent (discounted), short-term costs matter more. The Bellman equation is that exact decomposition, made formal.

---

## Two Flavours of Bellman Equation

There are two families you must be able to write from memory:

1. **Bellman Expectation Equation** — used when you know the policy π.
2. **Bellman Optimality Equation** — used when you want the *best* policy.

The expectation form averages over actions the policy takes; the optimality form picks the *best* action with `max`.

---

## Bellman Expectation Equation for v_π

For a state-value function `v_π(s)` (expected return starting from `s` and following π):

```
v_π(s) = Σ_a π(a|s) Σ_{s', r} p(s', r | s, a) [ r + γ v_π(s') ]
```

Read it left to right:

- `π(a|s)` — the policy's probability of choosing action `a` in state `s`.
- `p(s', r | s, a)` — the environment's probability of landing in `s'` and producing reward `r`.
- `r` — the immediate reward.
- `γ v_π(s')` — the discounted value of the next state.

> **Joke to remember it:** "**P**olicy picks action, **E**nvironment picks outcome, **R**eward is grabbed, **D**iscount is applied" — PERD. Then you sum, sum.

### Backup diagram (text form)

```
        (s)
       / | \
      a1 a2 a3      <-- policy weights π(a|s)
     /   |   \
   r+γv  r+γv  r+γv <-- one-step backups
       v_π(s)       <-- weighted sum = value of s
```

This is "unrolling one step of the future" and averaging the branches.

---

## Bellman Expectation Equation for q_π

For the action-value function `q_π(s, a)` (expected return after taking action `a` in `s`, then following π):

```
q_π(s, a) = Σ_{s', r} p(s', r | s, a) [ r + γ Σ_{a'} π(a'|s') q_π(s', a') ]
```

Notice the structure:

- First sum is over **environment** outcomes (`s', r`) given the fixed action `a`.
- Inside, you take the reward plus the discounted value of `s'`.
- The value of `s'` is then written in terms of `q_π(s', a')` averaged over the policy's next action.

### Backup diagram for q_π

```
        (s, a)              <-- state-action
       /      \
     s', r     s'', r''     <-- environment transitions
       |          |
   r + γ Σ_a' π q   r + γ Σ_a' π q
   = q_π(s, a)
```

### Relationship between v_π and q_π

You can also write a useful one-line identity:

```
v_π(s) = Σ_a π(a|s) q_π(s, a)
```

`v_π` is the policy-weighted average of `q_π`. This little equation shows up constantly — it's the bridge between "state values" and "action values."

---

## Bellman Optimality Equation for v_*

The optimal state value picks the **best** action, not an average:

```
v*(s) = max_a Σ_{s', r} p(s', r | s, a) [ r + γ v*(s') ]
```

- `v*(s)` is the value of `s` under the **optimal policy** π*.
- The `max_a` says: "an optimal agent will choose the action with the highest expected return."

> **Analogy:** You're at a fork in the road. The expectation equation says "average over both directions weighted by how often I take them." The optimality equation says "I'll only ever take the better of the two."

---

## Bellman Optimality Equation for q_*

For optimal action values:

```
q*(s, a) = Σ_{s', r} p(s', r | s, a) [ r + γ max_{a'} q*(s', a') ]
```

The `max_{a'}` inside is the only difference from the expectation version of `q_π`: after seeing the new state, an optimal agent will then pick its best available action.

And the optimality bridge:

```
v*(s) = max_a q*(s, a)
```

The optimal value of a state is the best action you could take from it.

## Worked Example — 4-State Grid (C, A, B, D)

The lecture walks through a 4-state MDP, **C → A → B → D**, with the following properties:

- Reward = 0 everywhere **except** state B, which gives +5.
- The agent follows a **random policy**: each of the four actions (up, down, left, right) is taken with probability 1/4.
- `γ = 1` for simplicity (no discounting in the worked numbers).

### Computing v_π(A)

From state A the four possible actions give:

| Action | Next state | Reward | Probability under random π |
|--------|-----------|--------|----------------------------|
| Right  | B         | +5     | 1/4                        |
| Down   | C         | 0      | 1/4                        |
| Up     | A         | 0      | 1/4                        |
| Left   | A         | 0      | 1/4                        |

Plugging into the Bellman expectation equation:

```
v_π(A) = (1/4)(5 + v_π(B)) + (1/4)(0 + v_π(C)) + (1/4)(0 + v_π(A)) + (1/4)(0 + v_π(A))
```

### Solving the system

Writing one Bellman equation per state (`A, B, C, D`) and solving the linear system gives the unique values:

```
v_π(C) ≈ -2.3
v_π(A) ≈ -1.5
v_π(B) ≈  2.3
v_π(D) ≈  1.4
```

(Exact values depend on whether you use γ = 1 and the precise transition structure; the point is the *method*.)

### Why this matters

The lecture's punchline: **"The Bellman equation reduced an unmanageable infinite sum over possible futures to a simple linear algebra problem."**

That is, instead of enumerating every trajectory of every length (impossible for long horizons), the Bellman recursion lets you solve for values with a system of |S| linear equations — one per state. For tiny MDPs you can solve this directly; for big ones, you use iterative methods like value iteration.

> **Caveat the slide flags:** Direct linear-algebra solve is only practical for small problems. In realistic MDPs we use **iterative methods** (value iteration, policy iteration) and **sample-based methods** (TD learning, Q-learning) — both are still *rooted* in the Bellman equation.

## Concept Map

```
                 Bellman Equation
                  /          \
       Expectation               Optimality
        /     \                   /      \
      v_π(s)  q_π(s,a)        v*(s)    q*(s,a)
       \      /                 \      /
   v_π = Σ π·q_π            v* = max q*
```

Same skeleton, different operator on the action: average (expectation) vs. maximize (optimality).

---

## Key Takeaways

- The **Bellman equation** recursively defines a value in terms of the immediate reward plus a discounted successor value.
- The **expectation form** averages over actions chosen by the current policy π; the **optimality form** uses `max` to pick the best action.
- `v_π(s) = Σ_a π(a|s) q_π(s, a)` and `v*(s) = max_a q*(s, a)` — these two identities are the bridges between state- and action-values.
- A **backup diagram** is just the one-step unrolling of the Bellman equation as a small tree.
- In the worked grid example, writing one Bellman equation per state turns an intractable infinite-horizon sum into a small system of linear equations.
- For large MDPs you cannot solve the linear system directly — that's why we have **value iteration, policy iteration, and TD learning**, all of which are iterative ways of *approximately* enforcing the Bellman equation.
- Memorize the four boxed equations; exams almost always ask you to write at least one from scratch.
