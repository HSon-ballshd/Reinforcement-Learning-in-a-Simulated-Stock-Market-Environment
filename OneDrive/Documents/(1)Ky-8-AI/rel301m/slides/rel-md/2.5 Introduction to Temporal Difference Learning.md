# 2.5 Introduction to Temporal Difference Learning

Temporal Difference (TD) learning is one of the central ideas in reinforcement learning. It is the conceptual bridge between two worlds you have already seen in the course: **Monte Carlo (MC)** methods, which learn from complete episodes, and **Dynamic Programming (DP)**, which learns by bootstrapping off estimates of successor states. TD does both at the same time — it learns directly from raw experience (model-free) while still updating its estimates using its own predictions of future value (bootstrapping).

> **One-liner analogy:** TD is "learn from your prediction error after every single step." You don't wait until the end of the game to find out if you were right — the moment you see the next state and the reward, you adjust.

---

## Why TD Matters

- It is **model-free**: the agent does not need to know the transition probabilities `P(s'|s,a)` or the reward function. It only needs samples of experience.
- It **bootstraps**: it updates a guess toward another guess (the value of the next state), the same way DP does.
- It learns **online, step-by-step** — no need to wait for an episode to terminate. This makes it usable in continuing (non-episodic) tasks.
- It is the foundation of almost every modern deep RL algorithm: Q-learning, SARSA, DQN, and the actor-critic family are all TD methods.

---

## Core Concepts

### 1. The TD Target

After taking action `A_t` in state `S_t`, the agent receives an immediate reward `R_{t+1}` and lands in `S_{t+1}`. The **TD target** is the agent's best current guess of the return from `S_t` using the observed reward plus its own estimate of the value of `S_{t+1}`:

```
TD_target = R_{t+1} + γ · V(S_{t+1})
```

This is exactly one step of a Bellman backup — but built from a real sample, not a model.

### 2. The TD Error

The **TD error** `δ_t` is the difference between the TD target and the agent's current value estimate. It measures "how wrong was I about `S_t`, given what just happened?"

```
δ_t = R_{t+1} + γ · V(S_{t+1}) − V(S_t)
```

- If `δ_t` is **positive**, the world was better than expected → push `V(S_t)` up.
- If `δ_t` is **negative**, the world was worse than expected → push `V(S_t)` down.
- If `δ_t = 0`, your estimate is perfectly consistent with what happened — no update needed.

> **Joke / analogy:** TD error is the agent's "oops signal." The bigger the oops, the bigger the learning step.

### 3. The TD(0) Update Rule

TD(0) is the simplest member of the TD family — it looks exactly one step ahead. After observing the transition `(S_t, A_t, R_{t+1}, S_{t+1})`, it performs:

```
V(S_t) ← V(S_t) + α · [ R_{t+1} + γ · V(S_{t+1}) − V(S_t) ]
        └──────┬──────┘   └──────────────┬─────────────────┘
         old estimate          TD error (δ_t)
```

- `α ∈ (0, 1]` is the **learning rate** (step size). Small `α` = slow but stable; large `α` = fast but noisy.
- `γ ∈ [0, 1]` is the **discount factor**, controlling how much we care about future rewards.
- Only `V(S_t)` is updated; `S_{t+1}` is used but not modified on this step (in the on-policy version).

The bracketed quantity is the **TD error** `δ_t`. So you can also write the update compactly as:

```
V(S_t) ← V(S_t) + α · δ_t
```

## TD vs. Monte Carlo vs. Dynamic Programming

This comparison is the cleanest way to see what TD actually adds.

| Property | Dynamic Programming (DP) | Monte Carlo (MC) | TD(0) |
|---|---|---|---|
| Needs model of environment? | Yes | No | No |
| Bootstraps? | Yes | No | Yes |
| Updates when? | Any time (full sweep) | End of episode | After every step |
| Uses sampled return? | No (uses expected) | Yes (full sampled return) | Yes (one-step sample) |
| Works in continuing tasks? | Yes | No (needs episode end) | Yes |

In symbols, the three update rules look like this for estimating `V(S_t)`:

- **DP** (expectation of next values, using a model):
  `V(S_t) ← E_π[ R_{t+1} + γ · V(S_{t+1}) | S_t ]`
- **MC** (sample the full return, no bootstrap):
  `V(S_t) ← V(S_t) + α · [ G_t − V(S_t) ]`
- **TD(0)** (one-step sample, bootstrap from `V(S_{t+1})`):
  `V(S_t) ← V(S_t) + α · [ R_{t+1} + γ · V(S_{t+1}) − V(S_t) ]`

TD is literally MC's target `G_t` replaced with a one-step bootstrap target. That's the entire conceptual leap.

## A Real-Life Analogy: The Daily Commute

Imagine you drive to work every morning and try to estimate how long the trip will take.

- **Monte Carlo style:** You only update your estimate after you have actually arrived at work and looked at the clock. Lots of wasted time if the estimate was bad.
- **DP style:** You'd need a perfect model of traffic lights, weather, and other drivers. Not realistic.
- **TD style:** Halfway through the drive, you glance at the clock. If the trip is going faster than you predicted, you revise your estimate downward *right now*, without waiting to reach the office. The TD target is "reward so far + discounted estimated time remaining" and the TD error is the difference between that and your original guess.

This is exactly the same structure: observe an immediate signal (time elapsed), combine it with your current estimate of the rest, and correct the original estimate.

---

## Worked Example: Two-State Grid World

A classic illustration: states `A` and `B`, goal `B` gives reward `+1` and ends the episode, all other transitions give `0`. Suppose we start with `V(A) = 0.5`, `V(B) = 0`, and `γ = 1`. The agent transitions `A → B`, receives `R = 1`.

1. **TD target:** `R + γ · V(B) = 1 + 1 · 0 = 1`
2. **TD error:** `δ = 1 − V(A) = 1 − 0.5 = 0.5`
3. **Update with α = 0.1:** `V(A) ← 0.5 + 0.1 · 0.5 = 0.55`

After enough episodes, `V(A)` converges toward the true expected return from `A`, and the agent's value estimates become accurate enough to drive good decisions.

## From TD to Control: Why This Leads to Q-Learning

The slides also flag that TD can be lifted from value prediction to **policy improvement** by switching from state values `V(s)` to **action values** `Q(s, a)`. Once you can estimate `Q`, you can act greedily with respect to it. **Q-learning** is the off-policy TD control algorithm built on this idea, and is the topic of the next lecture. For now, just remember the bridge:

> TD on `V` → **TD prediction**
> TD on `Q` + greedy action selection → **TD control** (Q-learning, SARSA)

---

## Key Takeaways

- **TD learning is model-free but bootstraps** — it combines the best of MC (no model, sample-based) and DP (online, uses value estimates).
- The **TD target** `R_{t+1} + γ · V(S_{t+1})` is a one-sample, one-step approximation of the return.
- The **TD error** `δ_t = R_{t+1} + γ · V(S_{t+1}) − V(S_t)` is the discrepancy between what you predicted and what you just observed; it drives the update.
- The **TD(0) update** is `V(S_t) ← V(S_t) + α · δ_t` — adjust your current estimate by a fraction of the prediction error.
- Unlike MC, TD does **not need to wait** until the end of an episode, so it works in continuing tasks and can learn online.
- Choosing `α` and `γ` matters: too large a step size causes oscillation; too small makes learning painfully slow.
- TD on action values `Q(s, a)` is the launchpad for **Q-learning** and the entire family of TD control algorithms that dominate modern deep RL.
